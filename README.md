# أدعية إسلامية (Flask)

A clean and modern Islamic web app inspired by Islambook-style sections, built with Flask.

## Features

- Quran page with searchable verses.
- Hadith page with book-based filtering.
- Azkar page (morning, evening, after salah).
- Prayer times page by city/country (Aladhan API).
- Responsive modern interface (Bootstrap + custom CSS).

## Quick Start

1. Create and activate a virtual environment.
2. Install dependencies:

   pip install -r requirements.txt

3. Run app:

   python app.py

4. Open in browser:

   http://127.0.0.1:5000

## Notes

- Content is structured and curated for demonstration and learning.
- You can expand data in [data/content.py](data/content.py).

# تحليل السوق السعودي (تاسي)

قسم إضافي داخل نفس تطبيق Flask لتحليل أسهم السوق السعودي فنيًا وفق
استراتيجية مكتوبة ومُختبَرة. **ليس توصيات استثمارية ولا حكمًا شرعيًا.**

## ما الذي يفعله

| الصفحة | الوصف |
|---|---|
| `/market` | لوحة السوق: المؤشر العام، حالة السوق، قوائم مرتّبة (مرشحة للصعود / تحت المراقبة / مرشحة للهبوط / الخاسرة / الأعلى ارتفاعًا وانخفاضًا / الأنشط سيولة) وأداء القطاعات. |
| `/market/<رمز>` | تحليل السهم: شارت شموع تفاعلي مع المتوسطات والدعوم والمقاومات وخطوط الاتجاه والحجم، البوابات الخمس، نماذج الدخول، قائمتا التأكيد والفيتو، الدرجة المركّبة، خطة التنفيذ، والنطاق المتوقع. |

### الاستراتيجية

كل قاعدة موثّقة في **[docs/STRATEGY.md](docs/STRATEGY.md)** — وهي مواصفة تنفيذية،
كل رقم فيها ثابت مسمّى في `market/analysis.py`. باختصار: خمس بوابات متتابعة
(سيولة ← حالة السوق ← اتجاه السهم ← إشارة دخول ← مخاطرة مقبولة)، أربعة نماذج
دخول، قائمة تأكيد وقائمة فيتو، ثم درجة مركّبة من سبعة مكوّنات موزونة.

ثلاثة أنماط بمعاملات منفصلة يختارها المستخدم من الواجهة: **مضاربة يومية**،
**مضاربة متأرجحة** (الافتراضي)، **استثمار طويل**. ورأس المال ونسبة المخاطرة
حقلا إدخال يُعاد على أساسهما حساب أحجام المراكز فورًا.

### مصدر البيانات ووضع عدم الاتصال

البيانات الحقيقية تُجلب من واجهة الرسوم العامة لدى Yahoo Finance برموز تداول
مضافًا إليها `.SR` (مثل `2222.SR`) — بلا مفتاح ولا تسجيل.

إذا تعذّر الاتصال (بيئة مغلقة، أو `MARKET_OFFLINE=1`) يتحوّل التطبيق إلى
**وضع تجريبي** يولّد مسارًا سعريًا اصطناعيًا ثابتًا لكل رمز، ويعرض تنبيهًا
أصفر صريحًا في أعلى كل صفحة. لا تُعرض بيانات مولّدة على أنها حقيقية أبدًا.

### متغيّرات البيئة

| المتغيّر | الافتراضي | الغرض |
|---|---|---|
| `MARKET_OFFLINE` | — | `1` يفرض الوضع التجريبي بلا أي طلب شبكة |
| `MARKET_PROVIDER_HOST` | `query1.finance.yahoo.com` | مضيف المزوّد الأساسي |
| `MARKET_TIMEOUT` | `12` | مهلة الطلب بالثواني |
| `MARKET_MAX_WORKERS` | `8` | عدد الطلبات المتوازية في المسح |
| `MARKET_TTL_INTRADAY` | `180` | مدة التخزين المؤقت للأطر اللحظية |
| `MARKET_TTL_DAILY` | `900` | مدة التخزين المؤقت للأطر اليومية |

### تحديث قائمة الشركات

`market/symbols.py` يحوي كون انطلاق من ١٥١ شركة في السوق الرئيسية. الأسماء
تُؤخذ من المزوّد عند توفّره، ولتحديث القائمة المخزّنة:

```bash
python tools/refresh_symbols.py          # يكتب market/symbols_override.json
python tools/refresh_symbols.py --check  # عرض بلا كتابة
```

تحقّق دائمًا من الرموز والأسماء مقابل [السوق المالية السعودية (تداول)](https://www.saudiexchange.sa).

### فتح التطبيق من الجوال على نفس الشبكة

خادم Flask الافتراضي يستمع على `127.0.0.1` فقط، و `127.0.0.1` على الجوال
يعني **الجوال نفسه** — لذلك تظهر `ERR_CONNECTION_REFUSED`. الحل:

```bash
HOST=0.0.0.0 python app.py
```

سيطبع التطبيق عند الإقلاع رابطًا جاهزًا مثل `http://192.168.1.15:5000/market`
افتحه من متصفح الجوال، بشرط أن يكون الجوال والكمبيوتر على **نفس شبكة الواي فاي**.

| المتغيّر | الافتراضي | الغرض |
|---|---|---|
| `HOST` | `127.0.0.1` | `0.0.0.0` يفتح الخادم لأجهزة الشبكة المحلية |
| `PORT` | `5000` | منفذ الخادم |
| `FLASK_DEBUG` | `1` | يُعطَّل تلقائيًا عند الاستماع لغير `127.0.0.1` |

**ملاحظة أمنية:** مصحّح Werkzeug يسمح بتنفيذ كود عن بُعد، لذا يُعطَّل تلقائيًا
عند الربط على `0.0.0.0` — لا تعطّل هذه الحماية يدويًا.

**إن لم يفتح رغم ذلك:**

- **الجدار الناري** يحجب المنفذ. في ويندوز ستظهر نافذة إذن عند أول تشغيل — اختر
  «السماح» للشبكات الخاصة. في macOS: الإعدادات ← الشبكة ← جدار الحماية.
- **على macOS المنفذ 5000 محجوز** لخدمة AirPlay Receiver. استخدم منفذًا آخر:
  `HOST=0.0.0.0 PORT=5001 python app.py`
- **شبكات الضيوف والفنادق** تعزل الأجهزة عن بعضها (client isolation) فلا ينفع
  الاتصال بينها مهما فعلت — استخدم شبكة منزلية أو نقطة اتصال من الجوال.
- بدل كل ذلك: انشر التطبيق على Render (ملف `render.yaml` جاهز) وافتحه من أي مكان.

### الاختبارات

```bash
pip install pytest
pytest tests/ -q      # ٧٨ اختبارًا، كلها بلا اتصال شبكة
```

تغطّي: صحة المؤشرات مقابل قيم معروفة، مطابقة المحرّك لوثيقة الاستراتيجية
(كل بوابة وكل فيتو)، حسابات حجم المركز والوقف والأهداف، منطق الماسح، وواجهات
HTTP. من بينها اختبار مرجعي يبني وضعًا مثاليًا ويتأكد أنه يجتاز البوابات الخمس —
حتى لا تتشدّد القواعد يومًا لدرجة استحالة أي صفقة دون أن يلاحظ أحد.

### حدود يجب معرفتها

- تحليل فني بحت: لا يقرأ الأخبار ولا القوائم المالية ولا التقييم.
- بيانات المزوّد العام قد تتأخر عن السوق الفعلي.
- **لا يعطي حكمًا شرعيًا** — الفلترة الشرعية مرجعها الجهات المعتمدة.
- لا يضمن الربح. غرض الاستراتيجية جعل الخسارة صغيرة ومنضبطة، لا إلغاءها.
